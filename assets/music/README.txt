Put your own copy of "About You" by The 1975 in this folder.

Any of these names work: About You.mp3, about_you.mp3, The 1975 - About You.ogg ...
(mp3, ogg, wav, flac or opus)

The song isn't included because it's copyrighted. Until you add it, the
animation plays the piano track in the project folder, or a soft built-in pad
if there is no audio file at all.
